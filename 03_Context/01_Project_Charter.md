# Project Charter
## Microsoft 365 User & IT Support Administration Lab

### 1. Project Information
- **Project Name:** Microsoft 365 User & IT Support Administration Lab
- **Project Manager:** Youssef Rbiai
- **Date Started:** 25/09/2026
- **Target Completion:** 23/09/2026
- **Version:** 1.0

### 2. Business Justification (Why this project exists)
Microsoft 365 is the standard productivity platform for businesses in the UAE. 
IT Support Specialists receive daily tickets about: users cannot sign in, 
Outlook not working, Teams meetings failing, OneDrive not syncing, and 
permission problems in SharePoint. 

This project exists to build hands-on troubleshooting documentation for the 
10 most common Microsoft 365 support incidents, using official Microsoft 
Learn resources and realistic simulations, so that a Junior IT Support 
candidate can demonstrate job-ready skills to UAE employers.

### 3. Project Objectives (SMART)
1. Document the Microsoft 365 Admin Center structure and user lifecycle 
   (create, license, reset password, delete, restore) using official 
   Microsoft terminology.
2. Create 10 realistic support ticket scenarios covering: sign-in failures, 
   password resets, MFA issues, Outlook authentication, Teams sign-in, 
   OneDrive sync, SharePoint permissions, and license assignment errors.
3. For each ticket, apply the 7-step methodology: Identify → Isolate → 
   Test → Root Cause → Fix → Verify → Document.
4. Produce a portfolio-ready documentation set that can be shown to 
   interviewers as proof of practical understanding.

### 4. Scope
**In Scope (what we will do):**
- Study official Microsoft Learn modules (free)
- Practice user/account concepts using local PowerShell and simulations
- Write realistic support tickets with full troubleshooting steps
- Document environment constraints honestly
- Build a professional project portfolio

**Out of Scope (what we will NOT do — very important):**
- We will NOT administer a real Microsoft 365 tenant (no paid subscription)
- We will NOT claim hands-on experience with Exchange Online, Teams Admin 
  Center, or SharePoint Admin Center
- We will NOT perform actions that require Global Administrator privileges
- We will NOT use fake screenshots or claim tasks we did not perform

### 5. Environment & Constraints
- **Available:** 
  - Microsoft Learn free training modules (official Microsoft content)
  - Local Windows/Mac/Linux machine with PowerShell 7
  - Free Microsoft 365 Developer Program account (no sandbox eligibility)
  - Text editor (VS Code) for documentation
  - Web browser for Microsoft 365 admin center walkthroughs (read-only 
    documentation, not live tenant)

- **Not Available:** 
  - Microsoft 365 E5 Developer Sandbox (account not eligible)
  - Paid Microsoft 365 Business/Enterprise subscription
  - Global Administrator access to any live tenant
  - Exchange Online, Teams, SharePoint admin centers (live)

- **Workaround:** 
  - Use Microsoft Learn official documentation and screenshots
  - Practice PowerShell commands locally with simulated output
  - Create detailed "what I would click" documentation with official 
    Microsoft UI references
  - Label all theoretical knowledge as "Studied" not "Completed"

### 7. Success Criteria
1. 10 support ticket scenarios fully documented with root cause analysis
2. All documentation uses correct Microsoft terminology (no made-up terms)
3. Every claim in final CV entry is backed by actual work performed
4. Project can be explained in a 5-minute interview without notes

### 8. Risks & Mitigation
